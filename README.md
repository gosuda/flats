# Flats

Self-hosted, agent-agnostic web hosting. Each hosted site is a *flat*: coding agents create and deploy flats over MCP, CLI or HTTP API, and the operator manages them in a tailnet-only web console. Private flats are served over Tailscale; public flats go out through Portal.

Status: planning. The whole stack is planned as a single CGO-free Go binary.
